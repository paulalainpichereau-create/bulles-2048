# Bulles 2048

Jeu de fusion physique pour téléphone : lâche des bulles numérotées dans un bocal, fusionne les paires identiques (2+2 → 4, 4+4 → 8…) et atteins 2048 sans faire déborder le bocal.

**Jouer :** https://paulalainpichereau-create.github.io/bulles-2048/

## Comment jouer
- Glisse le doigt pour viser, relâche pour lâcher la bulle.
- Deux bulles identiques qui se touchent fusionnent ; les fusions enchaînées multiplient les points.
- Si une bulle reste au-dessus de la ligne pointillée trop longtemps, la partie est perdue.

## Outils
- 📍 **Aiguille** : éclate une bulle au choix (1 au départ, d'autres avec les points, 2 max).
- 〰️ **Secousse** : secoue le bocal, une fois par partie.
- ⚙️ **Options** : style Bonbons ou Aquarium, et nouveautés activables une par une (joker, échange, cascade, bulle fragile, missions, mode Zen).

Un seul fichier `index.html`, sans dépendance à installer.
